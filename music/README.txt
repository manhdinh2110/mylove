Thư mục nhạc riêng (tuỳ chọn)

Nếu bạn có file nhạc của riêng mình (bản tự thu, bản đã mua quyền...), đặt file .mp3 vào đây,
rồi trong Cài đặt → Nhạc, dán link dạng:  music/ten-bai.mp3

Lưu ý: repo GitHub công khai thì ai cũng tải được file trong này — không nên đưa nhạc có bản quyền lên.
Cách khuyến nghị là dán link YouTube của bài hát.
